# Our Days — รุ่นล็อกอินและบันทึกข้อมูลออนไลน์

เว็บนี้ใช้ Firebase Authentication (อีเมล/รหัสผ่าน) และ Cloud Firestore เก็บรูปกับกิจกรรมในบัญชีของผู้ใช้แต่ละคน มีไฟล์ `index.html`, `signup.html`, `app.js`, `signup.js`, `firebase-config.js` และ `firestore.rules` ให้พร้อมใช้งานหลังตั้งค่า Firebase

## ตั้งค่า Firebase

1. เปิด https://console.firebase.google.com/ แล้วสร้าง Project
2. ที่ Project settings > Your apps เพิ่ม Web app จากนั้นคัดลอกค่า `firebaseConfig` มาแทนค่าตัวอย่างใน `firebase-config.js` ให้ตรงทั้ง 4 ช่อง (`apiKey`, `authDomain`, `projectId`, `appId`)
3. ที่ Authentication > Sign-in method เปิด Email/Password
4. ที่ Firestore Database กด Create database เลือก Region ที่ต้องการ แล้วเปิดแท็บ Rules วางเนื้อหาจาก `firestore.rules` และกด Publish **ก่อน**ใช้แอปจริง ห้ามเปิดกฎแบบ `allow read, write: if true`
5. ที่ Authentication > Settings > Authorized domains เพิ่มโดเมนเว็บที่ใช้เผยแพร่ หากยังไม่มี
6. เปลี่ยนชื่อ `index.html` ไม่จำเป็น — ตั้งชื่อนี้ไว้แล้ว อัปโหลดไฟล์เว็บทั้งหมด (`index.html`, `signup.html`, `app.js`, `signup.js`, `firebase-config.js`) ในโฟลเดอร์เดียวกันไปยัง Netlify หรือบริการโฮสต์เว็บแบบ Static หลังจากนั้นเปิด URL ที่ได้และสร้างบัญชี

## ข้อมูลเก่า

เปิดแอปไฟล์เดิม > กด **ส่งออก** แล้วนำไฟล์ JSON ไป **นำเข้า** ในเว็บใหม่หลังเข้าสู่ระบบ การนำเข้าจะเพิ่มกิจกรรมและแทนค่าชื่อ/วันที่เริ่มคบ/รูปคู่ หากนำเข้าซ้ำกิจกรรมจะซ้ำด้วย ควรตรวจจำนวนรายการก่อนนำเข้า

## ข้อจำกัดสำคัญ

- บัญชีแต่ละอีเมลมีข้อมูลแยกกัน รุ่นนี้ยังไม่มีระบบเชิญแฟนเข้ามาใช้ความทรงจำชุดเดียวกัน อย่าใช้รหัสผ่านร่วมกันเพื่อเลี่ยงข้อจำกัดนี้
- รองรับรูปต้นฉบับไม่เกิน 20 MB ระบบแปลงเป็น JPEG และย่อให้เหลือไม่เกินประมาณ 620 KB ก่อนเก็บ GIF จะเป็นภาพนิ่ง
- เนื่องจากรูปเก็บเป็นข้อความใน Firestore เหมาะกับจำนวนรูปไม่มาก หากจะเพิ่มรูปจำนวนมาก ควรย้ายไปใช้พื้นที่เก็บไฟล์โดยเฉพาะและตรวจค่าใช้จ่ายก่อน
- เว็บจะใช้งานไม่ได้ถ้าไม่มีอินเทอร์เน็ตหรือ Firebase ยังไม่ถูกตั้งค่า
- ควรกด **ส่งออก** สำรองข้อมูลเป็นระยะ

## หน้าใหม่และวันครบรอบ

- หน้า `signup.html` เป็นหน้าสมัครแยก มีการกรอกรหัสผ่านสองครั้งและตรวจว่าตรงกันก่อนส่งไป Firebase
- บันทึกวันเริ่มคบแล้วหน้าต่างจะปิดเมื่อ Firestore ยืนยันสำเร็จ หากบันทึกไม่สำเร็จ หน้าต่างจะยังเปิดพร้อมข้อความสาเหตุบนฟอร์ม
- เมื่อเปิดเว็บในวันครบรอบรายเดือนหรือรายปี จะแสดงเซอร์ไพรส์ครั้งแรกในแต่ละแท็บ และกดปุ่มเปิดดูซ้ำได้ รองรับการตั้งค่าลดการเคลื่อนไหว

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository สาธารณะชื่อ `our-days` และอัปโหลดไฟล์เว็บทั้งหมดในโฟลเดอร์นี้ไว้ที่ราก repository
2. ที่ Settings > Pages เลือก Deploy from a branch, branch `main`, folder `/ (root)` แล้ว Save
3. เมื่อได้ลิงก์ `https://USERNAME.github.io/our-days/` ให้เพิ่ม `USERNAME.github.io` ใน Firebase Authentication > Settings > Authorized domains
4. เว็บยังใช้ Firebase Authentication และ Firestore เป็นระบบบัญชี/ข้อมูล; GitHub Pages เผยแพร่ไฟล์เว็บเท่านั้น
